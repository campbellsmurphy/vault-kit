# 01: Projects

**Active work with a clear outcome and a deadline.**

A project is anything you are working towards finishing. When the outcome is
achieved (or abandoned), move the folder to `04-archive/`.

## Examples

- `2026-q3-methodology-refresh/`
- `client-a-controls-review/`
- `learn-duckdb/`

## Conventions

- One folder per project. Inside it, write notes freely. Do not pre-impose
  structure.
- Each project folder has an `index.md` with the goal, current status and next
  step, plus `status:` frontmatter. The agent maintains it during `/lint-wiki`.
- Cross link aggressively to `02-areas/` and `03-resources/`. Wikilinks
  (`[[note-name]]`) are how the graph gets built.
- Client engagements use the alias convention from the vault `CLAUDE.md`. The
  folder name is part of the note: `client-a-controls-review/`, not the client's
  real name.

## Directory

Add one line per active project as you create them. This list is the fastest way
for an agent to orient, so keep it current.
